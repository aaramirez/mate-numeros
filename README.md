# Sistemas numéricos

De los naturales a los complejos, construidos uno sobre otro: axiomas de Peano e inducción, enteros y racionales como cocientes, irracionales, el axioma del supremo, la construcción de los reales, decimales y aproximación, y los números complejos en forma polar.

**Ver en línea:** https://aaramirez.github.io/mate-numeros/
